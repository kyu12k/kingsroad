## 대상과 데이터

**헤비 유저 = 50절 이상 외웠고 최근 30일 안에 공부한 사람: 42명.** 404절을 다 외운 사람 7명(같은 번호 사본 제외).

| 보이는 것 | 수치 | 설문으로 알아낼 것 |
|---|---|---|
| 두 갈래 — **굳히는 사람**(백지·망각 위주, 약 6명) / **나아가는 사람** | 21명은 외운 절의 절반 넘게가 단계 1로 돌아가 있다(30일 넘게 복습 안 함). 예: 218절 중 215 · 372절 중 315 | 복습을 안 하는 **이유**: 몰라서 / 많아서 / 새 절이 좋아서 / 앱 밖에서 따로 해서 |
| 백지 | 써본 사람 55%, 그러나 외운 절 대비 **중앙 4%** | 백지가 어려운 점(타이핑, 시간, 틀리는 게 싫음, 몰랐음) |
| 첫 마디의 고난 | 써본 사람 5%(2명) | 알고는 있나 — 기능 인지도 |
| 망각 · 주소 · 구절 · 암송(음성) 고난 | 38% · 52% · 36% · 21% | 고난을 무엇으로 고르나, 메뉴가 이해되나 |
| 막히는 곳 | 사용자 본인 힌트의 83%가 절의 **처음 10%**(일지) | 스스로 느끼는 막힘(시작·중간·절 사이 연결) — 데이터와 맞는지 |
| 알림 | **42명 중 2명** | 왜 안 켰나(몰라서·귀찮아서·싫어서·아이폰) |
| 함께 | 친구 21% · 길드 17% | 함께가 도움이 되나, 원하는 형태 |
| 새 예루살렘·3D | 흔적 있는 사람 2~3명(꾸밈 1 · 도감 2), 생명나무 열매 21명 | 아는가, 동기가 되나, 무거운가 |
| 시간대 | 13~16시 · 21~22시 많음, 7~8시 작은 봉우리 | 언제 어떤 상황에서 하나(출퇴근·점심·잠들기 전) |
| 같은 번호 여러 계정 | 2명(사본 3개·2개) | 기기를 바꾸거나 로그인이 풀린 적 |

⚠️ 앱 **밖에서** 하는 암송(소리 내어 읽기, 손글씨, 예배 낭독, 함께 외우기)은 데이터에 안 잡힌다 — 설문으로만 알 수 있다.

## 원칙

- **7분 안**(객관식 위주 12문항 + 주관식 2). 길면 헤비 유저도 중간에 닫는다
- **데이터로 알 수 있는 건 묻지 않는다**(몇 절 외웠나, 몇 번 접속했나) — 이유와 느낌만 묻는다
- 두 갈래(굳히는 / 나아가는)는 같은 설문, 분기 문항 하나(Q4)
- 자기 평가 문항(Q6)은 **실제 데이터와 비교**한다 — "얼마나 정확히 자기 기억을 아는가" 자체가 연구 재료
- 응답을 번호(#태그)와 이을지 묻는다(동의한 사람만 데이터와 연결)
- 보상은 작게(💎 조금) — 크면 대충 답하는 응답이 섞인다

## 문항 초안

**A. 목표**
1. 킹스로드로 계시록을 외우는 이유는? (여럿) — 교회·공동체 과제 / 스스로의 목표 / 말씀을 가까이 / 게임이 재미있어서 / 기억력 훈련 / 기타
2. 목표는 어디까지인가요? — 계시록 전체 / 일부 장 / 정해 두지 않음 / 기타

**B. 공부하는 방식**
3. 앱을 열면 보통 무엇부터 하나요? — 새 절 / 복습 목록 / 백지 차례 / 고난 / 중간점검·보스전 / 그때그때 / 기타
4. (분기) 외운 절을 복습하지 않고 새 절로 넘어간 적이 많다면, 그 이유는? (여럿) — 복습이 있는지 몰랐다 / 복습이 너무 많이 쌓여 엄두가 안 났다 / 새 절이 더 재미있다 / 복습은 앱 밖에서 따로 한다 / 이미 외워서 필요 없다고 느꼈다 / 해당 없음
5. 앱 밖에서도 암송하나요? (여럿) — 소리 내어 읽기 / 손으로 쓰기 / 예배·모임에서 함께 / 녹음 듣기 / 안 함

**C. 내 기억**
6. 지금까지 외운 절 중 **원문 없이 처음부터 끝까지 쓸 수 있는 절**은 몇 % 정도라고 느끼나요? — 10% 미만 / 10~30 / 30~50 / 50~70 / 70~90 / 90%+
7. 막힐 때 주로 어디서 막히나요? — 절의 시작 / 절 중간 / 다음 절로 넘어갈 때 / 비슷한 절끼리 헷갈림 / 장 번호·절 번호

**D. 기능**
8. 다음 기능을 아나요 / 써봤나요? (표) — 백지 · 오늘 백지 차례 · 🔑 첫 마디의 고난 · 망각의 고난 · 중간점검 빈칸·백지 · 새 예루살렘(3D)
9. 백지를 자주 안 쓴다면 이유는? (여럿) — 타이핑이 힘들다 / 시간이 오래 걸린다 / 틀리는 게 싫다 / 아직 실력이 안 된다 / 몰랐다 / 해당 없음
10. 한 절씩 외우는 것과 몇 절을 묶어(중간점검·보스전) 외우는 것 중 어느 쪽이 더 잘 외워지나요? — 한 절씩 / 묶어서 / 비슷 / 모르겠다

**E. 계속하게 하는 것**
11. 알림을 켜지 않았다면 이유는? — 몰랐다 / 설정이 번거롭다 / 알림이 싫다 / 아이폰이라 안 됐다 / 켜 두었다
12. 계속하게 만드는 가장 큰 힘은? (하나) — 말씀 자체 / 랭킹·승점 / 보석·꾸미기 / 친구·길드 / 습관 / 공동체 과제 / 기타

**F. 열린 질문**
13. 그만두고 싶었던 순간이 있었다면 언제였나요?
14. 하나만 바꿀 수 있다면 무엇을 바꾸고 싶나요?

**마무리**: 응답을 내 암송 기록(번호)과 연결해 연구에 써도 될까요? — 예 / 아니요 · (예라면) 번호
